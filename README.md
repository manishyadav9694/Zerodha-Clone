# Zerodha Clone - Full Stack Trading Platform

This is a full-stack clone of Zerodha Kite platform. Built for learning MERN Stack.

### 🚀 Live Link
Deployed soon on Vercel

### 🛠️ Tech Stack Used
- **Frontend:** React.js, Bootstrap, CSS
- **Dashboard:** React.js, Chart.js, Material UI
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

### 📂 Folders
- `frontend` - Zerodha landing page (Home, About, Pricing, Signup)
- `dashboard` - Kite dashboard (Holdings, Orders, Positions, Funds)
- `backend` - API and Server logic

### ✨ Features I Built
- Pixel perfect Zerodha homepage clone
- Dashboard with real trading UI
- Buy/Sell orders
- Responsive for all devices

### 💻 Run This Project on Your PC
```bash
# 1. Clone repo
git clone https://github.com/manishyadav9694/Zerodha-Clone.git
cd Zerodha-Clone

# 2. Run Frontend
cd frontend
npm install
npm start

# 3. Run Dashboard in new terminal
cd dashboard
npm install
npm start

# 4. Run Backend in new terminal
cd backend
npm install
npm run dev
